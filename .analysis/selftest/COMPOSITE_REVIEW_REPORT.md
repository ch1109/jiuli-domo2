# 人工组合与剩余场景复核

2026-09-20。

## 修复

人工组合此前只写关系和占用，没有把组成行的字段证据带入草稿。本轮为每条原始查货行保存品牌、型号、产地、单位、数量、件数、净重、毛重证据，保留来源与缺失标记。所有委托值保持不变，不自动补值或推断模型结论。

组合数量、件数、重量明确要求人工复核；其他差异或缺失也进入待处理。沿用现有字段冲突入口，人工可查看来源后保留委托值或编辑，记录独立人工证据。此处“冲突”包含需要人工核验的组合项，不等于模型判定数值错误。没有把单箱数值自动当作组合合计。

修改 `lib/domain/actions.ts`、`lib/demo-store.ts`。真实 Prompt、模型请求响应与 fixture 未修改。

## 场景结果

- SC-17：页面完成补客户、首次匹配、两条 REALTEK 原始行组合、两条 ASL 同型号按明确数量人工选择、提交人工确认、冲突逐项复核、逐行确认。五条委托行完整保留，引用两个查货单。现有事实币种、总价为 UNKNOWN，最终封版被正确拒绝，未核销任何原始行。刷新后关系保留。
- SC-05、18、19：全量浏览器复跑中按各自配方分配完整原始行通过，无重复占用；缺少其他型号依据时禁止提交。仍不能宣称整单完成。

这些测试中的人工选择和“保留委托值”用于验证操作机制，不代替真实业务人员对产地和重量的审批，也不是新增模型结果。
