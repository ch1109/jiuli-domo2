# 真实整单样本清单

用途：Phase 0 的可维护样本入口。本文档只读汇总 `真实整单样本/` 和 `source_inventory.json`，不替代逐文件事实，也不改变真实样本。

## 统计口径

- “物理文件”按磁盘文件统计；当前 11 套样本共 72 份材料。
- 委托、查货、发票、箱单、参考结果按 `source_inventory.json` 的文档段统计；发票/箱单可能嵌在查货 PDF 中，不等于独立文件数。
- `UNKNOWN` 表示原始材料无法可靠确认，不补零、不按目录名推断客户，也不把参考结果当原始事实。
- “可关联场景”只表示该样本被场景数据引用；不表示业务动作、页面或 Playwright 验收已经通过。

## 维护规则

1. 新增或替换真实材料时，先更新 `source_inventory.json` 和源文件完整性基线，再更新本表汇总。
2. 不为了让场景成立而修改、移动、重命名 `真实整单样本/` 内文件。
3. 客户归属、缺页、共享重量、COO/COD 和手写值优先级未确认时，只登记为缺口并同步 `spec_final/OPEN_QUESTIONS.md`。
4. 场景变体只放在 `demo-generated/mock/scenario-overrides.json`，不得反写本表的真实样本事实。
