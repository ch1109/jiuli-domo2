## 现场主演示

固定样本：`2026(DG)ZW003`。

1. 上传真实 Excel 委托书 `智微智能导单文件-1767930508809.xlsx`。
2. 确认客户，解析并生成委托草稿。
3. 上传对应查货材料；扫描 PDF 明确进入“待人工复核”，由演示者录入已核实的品牌、型号、数量和产地。
4. 在工作台执行匹配，处理一个冲突字段和一个缺失字段。
5. 提交人工确认、逐行确认并封版。
6. 查看最终 25 列、来源摘要、版本差异、人工操作和商品核销状态。
7. 返回商品池或打开下一张委托，确认未使用商品仍可继续分配。

逐步话术和失败处理见 [DEMO_SCRIPT.md](./DEMO_SCRIPT.md)，场景状态见 [DEMO_ACCEPTANCE.md](./DEMO_ACCEPTANCE.md)。

## 已经可以演示

- 委托、查货、发票和箱单的本地材料接入；PDF、Excel、图片有明确解析状态。
- 真实 Excel 保留 Sheet 和原始行位置，并能转换成委托草稿。
- 扫描件不会显示“解析成功但没有业务数据”，而是进入人工复核。
- 客户隔离、首次匹配、候选选择、字段编辑、冲突确认、解绑、改配和增量核对。
- 25 字段详情、必填缺失提示、来源位置、版本差异和人工操作记录。
- 人工确认、最终 25 列核对单、来源摘要和已使用查货行核销。
- 刷新保留本地运行状态；恢复场景会明确清空该场景的运行结果。

## 当前限制

- 真实查货材料多数为扫描 PDF，当前只能走人工复核录入，不提供真实 OCR。
- 委托修订要求商品行数量稳定；增删行或没有稳定行标识时需人工复核。
- 辅助材料需要用户明确选择草稿，不自动猜归属。
- 21 个场景按“已通过 / 材料阻断 / 未执行”管理；可加载不等于业务已通过。
- 阶段计时只保留为内部演示记录，不作为 Demo 通过标准，控制台不突出展示。

## 本期不做

- 生产数据库与数据迁移。
- 真实鉴权、账号角色、多人并发和权限体系。
- 云端或外部文件服务。
- OCR 服务采购、部署和生产接入。
- 自动重量推断。
- 没有稳定行号时的全自动增删行识别。
- 完整任务队列、后台恢复、复杂监控和告警。
- 面向所有真实文件的通用字段智能识别。

现有解析恢复、阶段计时等能力可以作为演示辅助保留，但不继续扩展，也不作为本轮验收门槛。

## Demo 验收门槛

交付前必须稳定回答“是”：

1. 能从一份委托材料走到最终核对单。
2. 客户、商品池和占用关系隔离且可解释。
3. 缺失和冲突能在页面处理。
4. 最终结果能追溯到材料、原始行、关系和人工操作。
5. 材料不完整或解析失败时，页面明确说明为什么不能继续以及下一步动作。
